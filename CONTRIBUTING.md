# Guida alle Contribuzioni (Per Genitori Dev e Tech)

Grazie per voler contribuire a rendere il **Patto Digitale Familiare** un punto di riferimento aperto per la community!

Trattiamo le regole pedagogiche e familiari con lo stesso rigore di un progetto software.

## Flusso di lavoro (Workflow)

1. **Fork del repository:**
   Fai il fork di `genitori2d/PattoDigitale` sul tuo profilo GitHub.


2. **Crea un Branch dedicato:**
   ```bash
   git checkout -b feature/nuova-regola-social
   # oppure
   git checkout -b fix/correzione-fascia-12-14


3. **Apporta le tue modifiche:**
* Modifica o aggiungi i file nella cartella `/patti/`.
* Utilizza la sintassi Markdown standard per mantenere il testo leggibile.
* Mantieni un tono di voce costruttivo, chiaro ed empatico nei testi del patto.


4. **Registra e invia i cambiamenti (Commit & Push):**
* Salva le modifiche nel tuo repository locale usando il comando `git commit -m "docs: aggiunta clausola sull'uso dell'IA generativa nei compiti"`.
* Invia i cambi al tuo profilo su GitHub tramite il comando `git push origin feature/nuova-regola-social`.


5. **Apri una Pull Request (PR):**
* Torna sulla pagina principale del repository `genitori2d/PattoDigitale` e apri una **Pull Request** verso il branch `main`.
* Descrivi nel dettaglio la motivazione pedagogica o pratica della modifica proposta, specificando a quale fascia d'età si riferisce.
